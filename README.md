# Smart Helmet Violation Detection System

## Project Overview

This project aims to build a real-time Smart Helmet Violation Detection System using YOLOv10.

The system will detect:
- Helmet
- No Helmet
- Person
- Motorcycle

Future extensions include:
- Number Plate Detection
- OCR
- Buzzer Alert
- Violation Database
- Dashboard

## Research Paper

This project is based on a recent AI research paper on motorcycle helmet violation detection and extends it with additional real-world features.

## Tech Stack

- Python
- YOLOv10
- PyTorch
- OpenCV
- Git
