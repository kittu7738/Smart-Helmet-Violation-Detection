# Evaluation Protocols (AI City Track 5)

This directory contains evaluation tools and metric calculation scripts aligned with the AI City Challenge 2024 Track 5 standards.

---

### Evaluation Criteria:
- **Primary Metric**: mean Average Precision (mAP) across all 9 classes.
- **Evaluation Splits**: 100 test video sequences evaluated using official Track 5 ground truth.
- **Comparison**: Future performance will be benchmarked directly against the existing YOLOv8n baseline and the paper's reported score (mAP 0.4860).
